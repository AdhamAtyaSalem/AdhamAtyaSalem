## 📂 Featured Project

### 🏦 BYNance — Personal Finance Tracker & Dashboard

> **My first real-world data project.** A comprehensive bilingual (Arabic/English) personal finance system built entirely in **Excel**, tracking **1,287 transactions** across **5 accounts** over **11 months** (Jan–Nov 2025) in **BYN (Belarusian Ruble)**.

| Metric | Value |
|--------|-------|
| 💰 Total Income | **26,629 BYN** |
| 💸 Total Expenses | **14,860 BYN** |
| ✅ Net Savings | **11,769 BYN** |
| 📈 Savings Rate | **44.2%** |

**What I built:**
- 📋 **Transaction Database** — 1,287 records with 9 structured fields (date, category, account, amount, currency, tags, type, cash flow)
- 📊 **Pivot Analysis** — Expense breakdown by category, income by source, and month-over-month cash flow with native Excel PivotTables
- 📈 **Executive Dashboard** — 4 KPI cards showing financial health at a glance

**Key Insights Discovered:**
- 🔥 **Side-hustle income ("Second work": 8,504 BYN) exceeded primary salary ("Job": 7,808 BYN)** — proving that data reveals truths spreadsheets hide
- ⚠️ **March 2025 was the only deficit month (-199 BYN)** — flagged by month-over-month analysis
- 💸 **"Loan given" was the #1 expense category (2,809 BYN — 18.9%)** — social lending is invisible wealth unless you track it

**Tech used:** Excel • PivotTables • Data Validation • Conditional Formatting • Financial Modeling • Bilingual Data Architecture
